## 🚀 Getting Started

1. **Fork** the project  
2. **Clone** your fork  
3. **Follow** the [installation guide](README.md#🚀-getting-started)  
4. **Create** a branch following our [branching policy](docs/development/BRANCHING_POLICY.md)  
5. **Develop** following the technical standards  
6. **Test** your changes  
7. **Open** a pull request  

## 📋 PR Checklist

- [ ] Code follows project standards (frontend/backend)  
- [ ] Tests added or updated  
- [ ] Documentation updated if necessary  
- [ ] Branch follows naming policy
