# Project i18n Documentation

This document describes the configuration and usage of internationalization (i18n) in the project.

## 1. Technology used

We use [next-intl](https://next-intl-docs.vercel.app/) to handle internationalization.  
For configuration details and features, see the official documentation.

## 2. Architecture

- **i18n configuration:**  
  Internationalization configuration lives in `src/i18n`.

- **Locale-related components:**  
  Components that handle language live in `src/components/locales`, for example `LocaleSwitcher` which changes the app locale.

- **Translation files:**  
  Translations are stored in `/messages` as `{lang}.json` where `lang` is a locale (fr, es, en).  
  All project routes follow the locale prefix, for example:
  - `/en/campains`
  - `/fr/campains`

## 3. Translation files

Translation files use the `{lang}.json` format where `lang` is a locale (fr, es, en).
All files contain the same keys; these keys correspond to identifiers used in React components (`.tsx` files).

The value associated with each key is translated depending on the language.

You can add more advanced formatting (enums, variables, etc.).  
For more information, see the [next-intl documentation](https://next-intl-docs.vercel.app/).

Best practices:

- One key per page or module.
- Each key defines a value and a list of variables used by the corresponding component/page.

## 4. Library usage example

Here is an example of retrieving the locale and using translations in a React component:

```tsx
import { useLocale, useTranslations } from "next-intl";

const MyComponent = () => {
  // Get the current locale
  const currentLocale = useLocale();

  // Load translations for the component "MyComponent"
  const t = useTranslations("MyComponent");

  return (
    <div>
      <h1>{t("title")}</h1>
      <p>{t("about")}</p>
    </div>
  );
};

export default MyComponent;
```

In this example, the translation namespace is `MyComponent`. You can find it in the `{lang}.json` files (fr, es, en) with keys like "title" and "about":

```json
// In en.json
  "MyComponent": {
    "title": "Welcome to Chariot!",
    "about": "The ultimate roleplay tool."
  },
  "AutreModule": {
    "variableUne": "Cat",
    "variableDeux": "Dog"
  }

// In fr.json
  "MyComponent": {
    "title": "Bienvenue sur Chariot!",
    "about": "L'outil ultime pour le JDR."
  },
  "AutreModule": {
    "variableUne": "Chat",
    "variableDeux": "Chien"
  }
```

This example shows how to get the current locale and display translated texts using useLocale and useTranslations.

## 5. Add a new language 🌍

1. **Add a language file:**  
  Create a `lang.json` file (e.g., `es.json`) in the translations folder.

2. **Generate locales:**

  - 🚀 Run:
    ```bash
    npm run generate:locales
    ```
  - Or restart the server with:
    ```bash
    npm run dev
    ```

3. **Rename the language if needed:**  
  The language will be added with its locale name (e.g., `fr`, `en`). Update it in files where necessary.

Note 📝:
Languages already handled in `LocaleSwitcher` are not overwritten by the script.

Note 2 📝:
The generation script runs in **pre-build** and when starting `npm run dev`.
